# Calques du personnage humain

Le personnage de base est conservé dans ../idle.png, ../happy.png, ../sleep.png et ../action.png.
Les options de cheveux, hijab, vêtements et accessoires sont composées comme calques SVG indépendants par app.js.
Les palettes sont séparées pour la peau, les cheveux, les vêtements et les accessoires.
