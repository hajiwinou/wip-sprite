# WIP Island — dreamOS

## Compagnons disponibles

La collection comprend désormais **16 compagnons**, chacun avec quatre poses (`idle`, `happy`, `sleep`, `action`) : lapin, chat, tortue, pelote, poulpe, narval, escargot, grenouille, mouton, bouton, llama, étoile de mer, girafe, dalmatien, koala et crabe.

## Personnalisation

- Les couleurs du personnage humain restent personnalisables : peau, cheveux, coiffure, haut et accessoire.
- Un curseur permet de modifier la teinte de tous les compagnons en même temps.
- Les profils sont conservés dans `localStorage`.
- Les états de session utilisent les poses correspondantes : Pause → sommeil, Je tricote → joie, Projet fini → action.

## Fichiers

- `index.html` : version autonome à publier sur GitHub Pages.
- `wip-sprites/` : les 64 PNG sources individuels (16 compagnons × 4 poses).


Personnalisation supplementaire : coiffures et coupes additionnelles (dont hijab), accessoires humains et accessoires superposables pour compagnon (noeud, chapeau cowboy, fleurs, couronne, casquette, lunettes, echarpe, aureole, ailes), avec couleur d'accessoire reglable.
